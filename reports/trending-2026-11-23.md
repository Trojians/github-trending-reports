⭐ 72,738（今日 **+668**）· 🍴 6,425

**点评**：一个 Agent 技能，能就任意主题横跨 Reddit、X、YouTube、Hacker News、Polymarket 和全网做调研，再合成为一份有依据的总结。7.2 万星的体量说明"让 Agent 替我读网"已经是刚需，而它的打法很聪明：不自己造搜索引擎，而是把现有信息源拼成一条可复用的研究流水线，再用"有依据的总结"兜底可信度。

## 🧭 趋势信号

- **Skill 包正在成为能力的标准发行形态**：Claude-BugHunter、last30days-skill、academic-research-skills、wshobson/agents 集体上榜，能力不再以应用或库的形式出现，而是以可直接装进 Claude Code 等 Agent 的 skill 包形态分发——谁先把自家 know-how 打包成 skill，谁就先占住 Agent 的工具箱。
- **Agent 的边界正在从代码编辑器向外扩**：CLI-Anything 要让所有软件 Agent 原生可用，cli-agent-orchestrator 编排多个编码 CLI，phone-harness 让 Agent 直接控制手机，Agent 的操作对象已经从代码扩到命令行、手机与全网信息。
- **AI 落地越来越像"一人工作室"套件**：autoclip 一键出片、FreeVideo 本地跑视频生成、Ghost-Downloader-3 集大成下载器，今天的热门项目越来越少大厂基建，越来越多是给个人创作者准备的、开箱即用的生产力工具。
