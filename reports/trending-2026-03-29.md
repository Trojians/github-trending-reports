### 1. SakanaAI/AI-Scientist-v2
*   **项目链接**: [https://github.com/SakanaAI/AI-Scientist-v2](https://github.com/SakanaAI/AI-Scientist-v2)
*   **犀利点评**: 如果说第一代 AI Scientist 是在“玩票”，那么 v2 版本则是真正穿上了“实验室白大褂”。它不再满足于写简单的脚本，而是通过**Agentic Tree Search（智能体树搜索）**在科学发现的无限可能中寻找最优路径。SakanaAI 正在尝试将人类最顶尖的智力活动——“科研”进行工业化流水线改造。
*   **解决痛点**: 解决了传统科研中“假设验证”周期极长、人力成本高昂的问题。它能自动化地进行文献综述、实验设计、代码执行及论文撰写，让科学探索实现 24/7 不间断运行。

### 2. trustgraph-ai/trustgraph
*   **项目链接**: [https://github.com/trustgraph-ai/trustgraph](https://github.com/trustgraph-ai/trustgraph)
*   **犀利点评**: 纯向量检索（RAG）的“幻觉”已经让开发者头疼不已，而 TrustGraph 是给 AI 装上了一个有逻辑的“大脑地图”。它不只是存储数据，而是通过**图原生架构（Graph-native）**构建知识的血缘关系。这是从“概率预测”向“逻辑推演”进化的关键基建。
*   **解决痛点**: 解决了 RAG 在处理复杂关联查询时“断章取义”的问题，以及企业级应用中对知识溯源、结构化上下文检索的刚性需求。

### 3. microsoft/VibeVoice
*   **项目链接**: [https://github.com/microsoft/VibeVoice](https://github.com/microsoft/VibeVoice)
*   **犀利点评**: 微软出手，必属精品。在 OpenAI 的 GPT-4o 语音模式尚未完全开源生态化的当下，VibeVoice 填补了**开源领域高性能语音 AI** 的真空。它追求的是“Vibe（氛围感）”，这意味着语音交互正在从“机械播报”跨越到“情感共鸣”。
*   **解决痛点**: 解决了开源语音合成（TTS）和识别（ASR）中普遍存在的延迟高、语调生硬、环境鲁棒性差的问题，为下一代端侧 AI 助手提供了核心感官能力。

### 4. sickn33/antigravity-awesome-skills
*   **项目链接**: [https://github.com/sickn33/antigravity-awesome-skills](https://github.com/sickn33/antigravity-awesome-skills)
*   **犀利点评**: 这是一个典型的“军火库”项目。当大家还在讨论如何写 Prompt 时，这个项目直接提供了 **1326+ 个开箱即用的 Agent 技能**。它通过 CLI 模式将技能安装化，预示着未来 Agent 的开发将像安装 npm 包一样简单。它是 Claude Code 和 Cursor 等编程智能体的“外挂装甲”。
*   **解决痛点**: 解决了开发者在构建 Agent 时，需要为每个细分任务（如合规审查、C-level 咨询、特定工程操作）重复造轮子的低效困境。
