## ⚡ 今日头条

### [NVIDIA/SkillEvaluator](https://github.com/NVIDIA/SkillEvaluator)

⭐ 2,719（今日 **+873**）· 🍴 363

**一句话**：给 AI Agent 技能做「质检」的多层评估框架。

当所有人都在写技能、卖技能、拼技能数量的时候，NVIDIA 出手做了另一件事：给技能本身立规矩。SkillEvaluator 不评估模型，评估的是挂在 Agent 身上的技能和插件——质量门禁先卡一道，语义重叠检测揪出重复造轮子，合成评估数据集批量出题，最后还要在真实 Agent 运行中实测：装了这个技能，Agent 的行为到底变好了还是变坏了。

这正是当下最缺的一环。技能市场正在爆炸式生长，但「好用」全凭口碑和 Star 数，没有一把尺子。NVIDIA 把评估做成框架而不是一次性榜单，意味着它想当的不是裁判，而是质检标准的制定者。

**它解决的痛点**：技能泛滥但良莠不齐，开发者不知道该信哪个技能、该怎么证明自己的技能真的有效。

**结论**：`风向标`

### 2. [kajisho5/ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill) — 让编程 Agent 学会剪视频

⭐ 6,771（今日 **+367**）· 🍴 603

**点评**：42 个 FFmpeg 工具 + 机器可读的契约 + MCP 服务器，剪辑、字幕、重构画幅、响度、平台导出全包，而且本地跑、不用云、不用 API Key。视频处理是最吃工具链的活之一，这个技能的聪明之处在于不发明新轮子，而是把 FFmpeg 这套老牌瑞士军刀包成 Agent 能直接调用的接口。

### 4. [ifixai-ai/iFixAi](https://github.com/ifixai-ai/iFixAi) — 给 AI Agent 请个审计员

⭐ 46,082（今日 **+311**）· 🍴 1,819

**点评**：Agent 经济里最要命的问题不是 Agent 笨，而是你不知道它到底干了什么。iFixAi 做的就是独立审计——人审或 Agent 自审，120 秒内回答「它有没有按要求办事」。46,082 的总星数说明这不是新面孔，今天 +311 的增量说明市场终于开始为「信任」买单了。和头条的 SkillEvaluator 放在一起看，信号很清楚：Agent 的上半场拼能力，下半场拼可信度。

**痛点**：Agent 越来越自主，失控、跑偏、阳奉阴违的风险也随之放大，却没有一套现成的监督机制。

**结论**：`值得上手` ｜ 标签：#Agent审计 #可信AI #Agent经济
