## ⚡ 今日头条

### [tradermonty/claude-trading-skills](https://github.com/tradermonty/claude-trading-skills)

⭐ 5,582（今日 **+706**）· 🍴 1,176

**一句话**：给 Claude Code 装一套「交易员技能包」，市场分析、技术图表、经济日历、选股器、策略开发一站配齐。

+706 星断层登顶，比第二名多出一倍还不止——这不是偶然，是「AI 帮我炒股」这个念头终于从段子变成了人人想装的工具。它的打法很聪明：不自己造一个交易终端，而是把投资者的整套工作流拆成 Claude Code 能直接调用的 skills，让大模型在现成的对话里就能看盘、筛股、排日历。

值得注意的是方向选择：它瞄准的是散户投资者最日常、也最耗时的那几件事，而不是高频交易那种拼延迟的硬核战场。这让它既有话题性，又有真实可用性——今天的涨幅就是证明。

**它解决的痛点**：普通投资者想用 AI 辅助决策，却没有现成的、按交易流程组织好的工具链，只能一句一句现问现答。

**结论**：`风向标`

## 🔥 精选深读

### 1. [kajisho5/ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill) — 让 AI 助手本地剪视频的 42 件套工具箱

⭐ 5,977（今日 **+331**）· 🍴 528

**点评**：今日第二名，思路极其克制：不碰云、不要 API key，就把 FFmpeg 的 42 个工具用一份机器可读的契约包起来，再挂一个 MCP 服务器，Claude Code、Cursor、Codex 谁都能接。剪切、字幕、重构画幅、响度、平台导出全在本地跑完。视频处理是最吃「确定性」的活，AI 生成式剪辑噱头很多，但这个项目反其道而行之——AI 只负责理解需求和编排，真正干活的是 FFmpeg 这种三十年老兵，翻车率反而低。

**痛点**：编程助手想碰视频就得自己拼 FFmpeg 命令，参数多、易错、还没法跨工具复用。

**结论**：`值得上手` ｜ 标签：#AI编程 #视频处理 #MCP

### 2. [NVIDIA/SkillEvaluator](https://github.com/NVIDIA/SkillEvaluator) — 英伟达亲自下场，给 AI 技能打分的裁判

⭐ 1,706（今日 **+122**）· 🍴 232

**点评**：skills 满天飞的第二天，裁判就来了。英伟达这套框架做的是多层评估：质量门、语义重叠检测、合成评测集生成，再加 live 评估，实测某个 skill 到底让 agent 的行为变好了还是变差了。这正是今天榜单最缺的一环——人人都在发 skills，却没人能量化哪个真有用。英伟达的背书让它一出生就自带可信度，但也别急着全信：评估框架本身的偏见，同样需要时间检验。

**痛点**：AI skills 数量爆炸，却没有统一标尺判断优劣，装一堆「技能」可能反而拖垮 agent。

**结论**：`风向标` ｜ 标签：#AI评估 #Agent #NVIDIA

### 3. [bojieli/ai-infra-book](https://github.com/bojieli/ai-infra-book) — 一本把 AI Infra 讲透的开源中文书

⭐ 7,824（今日 **+127**）· 🍴 630

**点评**：今天榜上唯一的中文长内容，也是最「硬」的一个。李博杰的开源书稿从硬件约束和模型架构出发，用量化推导讲 LLM 推理与训练的系统设计，附全书正文、PDF、配套计算工具与实验。在满屏「给 AI 写技能包」的今天，它提醒了一件事：infra 层的理解才是决定你能不能把大模型真正跑便宜、跑稳的底功。能把系统设计写成可算、可验的书，比再发十个 skills 更稀缺。

**痛点**：AI Infra 知识散落在论文、博客和源码里，缺少一条从硬件到系统设计的量化主线。

**结论**：`值得上手` ｜ 标签：#AIInfra #开源书 #LLM

### 4. [davila7/claude-code-templates](https://github.com/davila7/claude-code-templates) — Claude Code 组件的「应用商店」

⭐ 33,762（今日 **+174**）· 🍴 3,984

**点评**：榜单总星数第三高的老将，今天又涨 174 星。它做的事很朴素：把 Claude Code 的 agents、commands、skills、hooks、MCP、settings、mods 收进一个开源注册表，再配一个 CLI，一键装配。当 skills 从手工作坊走向规模化，分发层就成了刚需——这个项目就是今天 skills 热潮背后的基础设施。3.9k forks 说明它不只是被收藏，还在被大量二次加工。

**痛点**：Claude Code 组件散落在各处，没有统一的发现、安装与管理入口。

**结论**：`值得上手` ｜ 标签：#ClaudeCode #开源生态 #效率工具
