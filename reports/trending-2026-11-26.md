### [elementalsouls/Claude-BugHunter](https://github.com/elementalsouls/Claude-BugHunter)

⭐ 23,050（今日 **+1652**）· 🍴 2,356

**一句话**：一套给 Claude Code 用的漏洞挖掘技能包，把外部红队攻防的经验沉淀成了可直接调用的 85 个技能。

它不是又一个扫描器，而是一套"方法论合集"：85 个技能、16 条斜杠命令，外加从 681 份已公开漏洞报告里提炼出的模式，覆盖 24 类核心漏洞，还附带企业身份与基础设施攻击矩阵。换句话说，它把红队专家脑子里那套"先看哪、再试哪"的打法，变成了 Agent 能直接执行的清单。

安全工具向来有两极分化：要么是笨重的扫描器，要么是只可意会的经验。这个项目走的是第三条路——让 AI Agent 按专家的套路去挖洞。对防御方来说是体检利器，对攻击研究者来说是现成的起手式。

**它解决的痛点**：漏洞挖掘高度依赖专家经验，新手无从下手、老手重复造轮子；这套技能包把经验变成了可复用、可组合的 Agent 能力。

**结论**：`风向标`

## 🔥 精选深读

### 1. [HKUDS/CLI-Anything](https://github.com/HKUDS/CLI-Anything) — 让所有命令行工具都长出 Agent 能力

⭐ 65,693（今日 **+1106**）· 🍴 5,977

**点评**：口号很狂——"Making ALL Software Agent-Native"。思路却很实在：不改写原有 CLI，而是在外面包一层，让任何命令行工具都能被 Agent 调用。港大团队出品，6.5 万星的体量说明这不是纸上谈兵，而是踩中了"Agent 工具化"这个真需求。

**痛点**：Agent 生态里工具接入成本太高，每个 CLI 都要单独写适配。

**结论**：`值得上手` ｜ 标签：#Agent #CLI #工具链

### 2. [mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill) — 让 Agent 先做功课再开口

⭐ 75,126（今日 **+945**）· 🍴 6,623

**点评**：一个看似朴素的技能：研究任意话题时，先去 Reddit、X、YouTube、HN、Polymarket 和全网扫一圈，再综合出一份有依据的总结。7.5 万星说明大家早就受够了 Agent 张口就来的"幻觉式回答"。它真正的价值不在代码量，而在立了一个规矩——先检索，再发言。

**痛点**：Agent 回答缺乏时效信息和真实来源，凭空编造还理直气壮。

**结论**：`值得上手` ｜ 标签：#Agent技能 #检索 #研究助手

### 3. [zhouxiaoka/autoclip](https://github.com/zhouxiaoka/autoclip) — 一个链接，一键出片

⭐ 16,178（今日 **+880**）· 🍴 2,333

**点评**：开源 AI 视频剪辑桌面工具：把播客、访谈、课程等长视频自动剪成短视频，顺带生成字幕、封面和发布文案，适配抖音、小红书、TikTok、Reels 与 YouTube Shorts。长视频转短视频是内容创作者每天都在付的"体力税"，AutoClip 把这道工序打包成了一键操作。国产作者、中文场景优先，在同类工具里定位很准。

**痛点**：长视频剪短视频耗时耗力，字幕、封面、文案每样都要手工做。

**结论**：`小而美，值得一试` ｜ 标签：#AI剪辑 #短视频 #效率工具

### 4. [jingyaogong/minimind](https://github.com/jingyaogong/minimind) — 两小时，从零训出你的 64M 大模型

⭐ 70,974（今日 **+826**）· 🍴 9,225

**点评**：7 万星的老牌教学项目，今天又冲回榜单。卖点没变：两小时、从零、训出一个 64M 的小模型。它不承诺你能训出 GPT，只承诺让你真正走完一次"大模型是怎么来的"。在人人都在调 API 的今天，愿意亲手训一个小模型的人反而越来越少——而这正是理解 LLM 最短的那条路。

**痛点**：大模型训练门槛高，多数人只会调 API，不懂模型从何而来。

**结论**：`值得上手` ｜ 标签：#LLM #教学 #从零实现
