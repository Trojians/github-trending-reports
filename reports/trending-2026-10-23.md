## ⚡ 今日头条

### [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify)

⭐ 132,983（今日 **+1408**）· 🍴 12,725

**一句话**：把整个代码库连同文档、SQL schema 和 PDF 一起变成可查询的知识图谱，还带一个开箱即用的 /graphify skill。

为什么它重要？传统 RAG 往向量库里塞代码块，检索出来的是碎片；graphify 的思路是先建图——函数、类、表、文档之间的调用和引用关系全部保留，问问题时沿着图走。这正好打中 AI 编程时代的最大痛点：代码库越来越大，Agent 却还在"盲搜"。它能跟 Claude Code 之类的 Agent 工具直接对接成 skill，说明它瞄准的不是搜索框，而是 Agent 的工作流。

**它解决的痛点**：代码库问答只靠文本检索时，跨文件的调用关系和 schema 语义根本捞不回来，Agent 回答全靠猜。

**结论**：`风向标`

### 2. [headroomlabs-ai/headroom](https://github.com/headroomlabs-ai/headroom) — 给 Agent 的"压缩饼干"，把 token 账单砍九成

⭐ 77,567（今日 **+517**）· 🍴 6,020

**点评**：描述写得很实在：工具输出、日志、文件、RAG 切块喂给 LLM 之前先压缩，编码 Agent 省 20% token，JS 场景省 60–95%。这是一个典型的"成本优化"型项目——不炫技，但每家跑 Agent 的公司都看得懂账。7.7 万星证明大家是真肉疼。选它是因为它是今天少数"务实派"里涨幅最猛的。

**痛点**：Agent 吃上下文如喝水，token 账单和延迟双重失血，却没人愿意重写 pipeline。

**结论**：`值得上手` ｜ 标签：#Token优化 #AI-Agent
